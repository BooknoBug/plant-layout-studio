# Plant Layout Studio

โปรแกรมวางผังโรงงานยาเม็ดบนแบบพื้นของสถาปนิก วาดห้องพร้อมเกรดและความดัน วางเครื่องจักร ประตู
เส้นทางไหล (คน / วัตถุดิบ / ผลิตภัณฑ์ / อุปกรณ์ / ของเสีย) ตรวจกฎแนว GMP ดู 3 มิติ ส่งออก DXF ซ้อนแบบใน AutoCAD ได้

## เปิดใช้
- ดับเบิลคลิก `index.html` (Chrome / Edge) ใช้ออฟไลน์ได้ หรือเปิดผ่าน GitHub Pages (Settings → Pages → `main` / root)
- ครั้งแรกในแต่ละเครื่อง: แท็บ **แบบพื้นหลัง** → **เปิดไฟล์แบบพื้นหลัง (.layout.json)** แล้วเลือกไฟล์ที่ได้รับมา
  เครื่องนั้นจะจำแบบไว้ ครั้งต่อไปเปิดโปรแกรมแล้วใช้ได้เลย

## ไฟล์ 2 ชนิด (ไม่อยู่ใน GitHub)
| ไฟล์ | คืออะไร | ใช้ยังไง |
|---|---|---|
| `ชื่อ.layout.json` | แบบพื้นหลัง (ผนัง เสา ตาราง) ทำจาก DWG ของสถาปนิก | เปิดครั้งเดียวต่อเครื่อง · ได้แบบใหม่ก็เปิดไฟล์ใหม่ ห้องที่วางไว้อยู่ที่เดิมตามพิกัด DWG |
| `ชื่องาน.json` | งานออกแบบ (ห้อง เครื่อง ประตู เส้นทาง) **รวมแบบพื้นหลังไว้ในไฟล์** | ⋯ → Draft และไฟล์โครงการ → บันทึกเป็นไฟล์ · เครื่องอื่นเปิดไฟล์เดียวได้ครบ |

Draft (💾 / Ctrl+S) เก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ย้ายเครื่องให้ใช้ไฟล์ `.json`

## โครงสร้าง repo
| ที่อยู่ | คืออะไร |
|---|---|
| `index.html` | โปรแกรมที่ใช้งานจริง (สร้างจาก `src/` ด้วย `tools/build.py` ห้ามแก้ตรงนี้) |
| `src/config.js` | ส่วนที่ปรับบ่อย: เครื่องจักร ประตู ประเภทห้อง เส้นทางไหล เกรด ACH |
| `src/app.js`, `src/style.css`, `src/index.html` | ตัวโปรแกรม |
| `tools/extract_sheet.py` | DWG (ผ่าน LibreDWG JSON) → แผ่นผังดิบ |
| `tools/layouts/*.py` | สูตรทำแบบพื้นหลังแต่ละชุด (ตัด/ตีตาราง/ตั้งชื่อ) → `.layout.json` |
| `tests/` | smoke test + แบบทดสอบจำลอง |
| `docs/DEVELOPER.md` | คู่มือปรับปรุงโปรแกรม · `CLAUDE.md` คำสั่งสำหรับ Claude Code · `CHANGELOG.md` ประวัติ |

## ข้อควรระวัง
- แบบพื้นหลังและไฟล์งานเป็นข้อมูลบริษัท อย่า commit `*.layout.json`, `source/`, ไฟล์ DWG (`.gitignore` กันไว้แล้ว)
- ค่าตั้งต้น (ความดัน ACH สภาวะห้อง ขนาดเครื่อง ระยะเว้น) เป็นค่าวางแผน ไม่ใช่ข้อกำหนด ต้องยืนยันกับผู้ออกแบบ HVAC ผู้ผลิตเครื่อง และ QA
